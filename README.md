# snow_trip

2027年始・6人1泊2日のスノーボード旅行の予算と旅程。

## 内容の更新

`2027_snowboard_trip_budget_clean.html` を編集後、`python3 sync_site.py` で公開用 `public/index.html` に反映します。費用の計算値はHTML内の `estimate` にあります。内訳の固定表示も合わせて修正してください。

`?plan=ryuoo` 付きURLで2日間とも竜王のプランを共有できます。通常は竜王→野沢温泉です。

## 検索除外

HTMLのrobotsメタタグとSites用 `_headers` でnoindexを指定しています。noindexはアクセス制限ではなく、URLを知っている人は閲覧できます。検索エンジンがタグを読めるようrobots.txtでクロール自体は拒否していません。

## 見積の前提

宿泊費などは元の見積を継承。竜王は1日券5,800円×日数、駐車場無料を仮置き。交通費・レンタル費はプラン間で据え置き。正式料金・予約条件は旅行前に確認してください。

宿の情報源：https://www.airbnb.jp/rooms/1033686182697114521 （2026-09-17確認）
